# CampusEats - System Brief

## WHAT

CampusEats is a campus food-ordering system. A student can use it to find restaurants, look at available food items, add items to a cart, place an order, pay for it, and follow the delivery. The system also keeps students updated through notifications.

## WHO

The system mainly involves:

- Students who order food
- Restaurants that provide the menus
- Riders who deliver the orders
- Payment services that handle payments and refunds
- Notification services that send updates

## NOUNS

The main things we need to keep track of are:

- Student
- Address
- Restaurant
- Menu
- Food item
- Cart
- Order
- Order status
- Payment
- Transaction
- Refund
- Rider
- Delivery assignment
- Notification
- Message

## VERBS

The main things users or services need to do are:

- Create and manage a profile
- Add or update an address
- View restaurants
- View menu items and prices
- Add items to a cart
- Place an order
- View an order
- Cancel an order
- Make a payment
- Process a refund
- Assign a rider
- Track a delivery
- Send a notification
